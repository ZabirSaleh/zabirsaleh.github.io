# Zabir Saleh — Professional Portfolio

A responsive GitHub Pages portfolio focused on RF, RAN and 5G/LTE network engineering, with supporting software and AI project case studies.

## Site structure

- `index.html` — professional profile, skills, experience, projects and contact
- `cv.html` — print-friendly web resume
- `projects/` — detailed project archive and case studies
- `assets/css/style.css` — shared visual system and responsive layout
- `assets/js/main.js` — navigation, contact links and progressive reveal behavior
- `assets/img/` — profile, favicon and social-sharing images

## Local preview

Serve the repository root with any static web server, then open `index.html`. No build step or package installation is required.

## Publishing

The repository is designed for GitHub Pages from the `main` branch at:

`https://zabirsaleh.github.io/`

## Contact configuration

Site-wide email, GitHub and LinkedIn links are maintained in `assets/js/main.js`.
