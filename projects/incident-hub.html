DHL Incident Hub

A secured incident-management workflow for capturing raw input, managing incident status, searching records and automating ingestion through UiPath.

Case study Problem Approach Key features Technology Outcome

Problem

Operational incidents may arrive through email, Drive, notes and mixed attachments. Without a structured workflow, teams lose traceability and spend time manually re-keying or cleaning information.

Approach

The web application provides secured access, upload and status workflows, while UiPath handles ingestion and duplicate checks. The backend exposes APIs for users, incidents and attachments with MySQL persistence.

Key features

  • Secured login and protected dashboard
  • Raw text/PDF/document upload
  • Draft → Reviewed → Published lifecycle
  • Incident search and filtering
  • UiPath ingestion from external sources
  • Duplicate checks and error logging

Technology

ReactViteNode.jsExpressMySQLJWTUiPathREST API

Outcome

The prototype creates a practical end-to-end incident pipeline in which intake, review, search and reporting share one structured source of truth.
