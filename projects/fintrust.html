FINTRUST

A secure fintech prototype combining strong authentication, transaction authorization, tamper-evident records and blockchain anchoring concepts.

RoleArchitecture, security flow, app prototype
StackFlutter • Node.js • MySQL

StatusPrototype / academic project

Case study Problem Approach Key features Technology Outcome

Problem

Client-side fintech logic can be modified or bypassed, creating risks around account takeover, transaction fraud, tampering and poor auditability.

Approach

Sensitive actions are shifted toward server-side verification. The design combines MFA, OTP-based transaction authorization, risk controls and SHA-256-based audit records, with proof hashes conceptually anchored to Ethereum Sepolia.

Key features

  • MFA-oriented login flow
  • OTP transaction authorization
  • Secure deposit and transfer workflow
  • SHA-256 ledger / audit trail concept
  • Blockchain proof anchoring
  • CSV/PDF export concepts

Technology

FlutterNode.jsExpressMySQLMFAOTPSHA-256Ethereum Sepolia

Outcome

FINTRUST demonstrates how application security, user experience and auditability can be designed together rather than added as isolated features at the end.
