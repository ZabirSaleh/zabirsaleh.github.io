RAN NMS Simulator

A BTS/eNodeB/gNodeB network-management simulator exploring fault, configuration, inventory, performance, security and task scheduling.

Problem

Telecom NMS functions are often difficult to experiment with in a small learning environment because real network elements and OSS integrations are complex and vendor-specific.

Approach

The simulator models common management functions and produces operational logs that can be inspected through CLI and web interfaces. Scheduling experiments compare non-preemptive SJF and priority-based execution.

Key features

  • Fault management simulation
  • Configuration and inventory management flows
  • Performance-management logging
  • Security / access function concepts
  • SJF and priority scheduling
  • CSV / JSON log generation

Technology

CHTML/CSS/JSCSVJSONNMSOSSScheduling

Outcome

The project provides a compact environment for demonstrating how network-management functions and scheduling policies interact without requiring a live RAN.
