UTM GreenLeaf

A sustainability-focused web system with registration, authentication, administrative evaluation, scoring, feedback and reporting.

Case study Problem Approach Key features Technology Outcome

Problem

Sustainability-related submissions and evaluations benefit from a structured system that separates public content, user registration and administrative review.

Approach

The application uses Spring Boot and Thymeleaf to manage user-facing pages and authenticated administrative workflows, with MySQL used for persistent data.

Key features

  • Public information pages
  • Registration and login
  • Administrative review
  • Score and feedback workflow
  • User-management functions
  • Report generation

Technology

JavaSpring Boot 3ThymeleafMySQLMavenMVC

Outcome

GreenLeaf demonstrates a complete Java web workflow from public pages to authenticated administration and reporting.

This portfolio page is intentionally written as an engineering case study: problem → approach → implementation → outcome.
